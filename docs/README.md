# Documentation guide

The repository documentation is grouped by purpose:

- `qr/` — QR mission design and implementation status.
- `return/` — return-journey design, status, and sensor-hold evidence.
- `validation/` — focused test evidence and replay results.
- `reviews/` — engineering reviews and audits.
- `archive/` — historical handoff copies retained for traceability.

The operational handoff remains `../world/HANDOFF.md`; the Pi-specific handoff is `../world/integration/PI_HARDWARE_HANDOFF.md`.
